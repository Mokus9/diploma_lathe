## 🎯 Зачем этот проект

Обработка резанием — историческая основа инженерного мышления — для младшей аудитории остаётся «за закрытой дверью»: настоящий токарный станок опасен (высокие обороты, сеть 220 В, разлетающаяся стружка). Существующие решения делятся на два полюса: уменьшенные «взрослые» станки, наследующие все опасности оригинала, и игрушки-имитации без реальной функции.

Этот станок закрывает незанятую нишу:

- ✅ Питание **7–12 В** от аккумулятора — сеть 220 В в рабочей зоне отсутствует полностью
- ✅ Обрабатывает **парафиновые свечи** — безопасно, доступно, наглядно
- ✅ Полностью **воспроизводим**: несущие детали печатаются на 3D-принтере
- ✅ Открытая система управления на **ESP32 + GRBL** — изучай и модифицируй
- ✅ Стандартный **G-код** — те же программы, что на взрослых станках
- ✅ **Себестоимость 4–6 тыс. ₽** — доступно для любого кружка или школы

## 🔌 Система управления

### Архитектура (три независимых контура)

```

          ▼  Wi-Fi (без кабеля)
      [ESP32]
      │      │
      │      ▼
      │  [TB6612FNG] ──► [NEMA17 · ось X]
      │  [TB6612FNG] ──► [NEMA17 · ось Y]
      │
      └──► [ШИМ] ──► [DC Motor 12В · шпиндель]

[Кнопка аварийного стопа] ──► разрыв питания всех контуров
```

- **Контур 1 · Оси X/Y:** ESP32 → TB6612FNG → шаговые двигатели
- **Контур 2 · Шпиндель:** DC 12В через ШИМ — плавная регулировка оборотов
- **Контур 3 · Аварийный стоп:** кнопка отключает всё одновременно

### Быстрый старт

```bash
# 1. Клонировать репозиторий
git clone https://github.com/m112521/mini-cnc-lathe.git

# 2. Открыть в Arduino IDE
# Файл: firmware/main.ino

# 3. Установить поддержку ESP32
# Boards Manager → esp32 by Espressif Systems

# 4. Выбрать плату ESP32 Dev Module, порт → Upload
```

Подробно: [`firmware/firmware_setup.md`](firmware/firmware_setup.md)

## 🔨 Сборка (9 этапов)

Полная инструкция: [`docs/assembly.md`](docs/assembly.md)

1. Распечатать все детали из PETG
2. Запрессовать подшипники 608 в корпус шпиндельного узла
3. Собрать шпиндель: болт → конус → шкив GT2
4. Собрать станину: алюминиевые трубки в опоры, проверить параллельность
5. Установить ходовые винты и шаговые двигатели
6. Установить заднюю бабку (конус на подшипнике)
7. Смонтировать платформу резцедержателя на печатных подшипниках
8. Подключить электронику по схеме, установить кожух из поликарбоната
9. Залить прошивку, откалибровать оси, установить Home

## 🛡️ Безопасность

Нормативная база: **ГОСТ 28139-89** и **ГОСТ Р «Оборудование учебное»** (с июня 2026).  
Новый стандарт устанавливает **7–12 В** как допустимое напряжение для начальной школы — станок соответствует.

| Категория | Меры |
|-----------|------|
| Механическая | Обороты ≤ 915 об/мин · поликарбонатный кожух 3 мм · кнопка аварийного стопа |
| Электрическая | Питание 7–12 В DC · нет 220 В · нет открытых контактов |
| Пожарная | Нет нагревателей · PETG и поликарбонат не воспламеняемы · крошка безопасна |
| Эргономическая | Шум ≤ 60 дБ · обзор через кожух · ремень гасит вибрацию |
